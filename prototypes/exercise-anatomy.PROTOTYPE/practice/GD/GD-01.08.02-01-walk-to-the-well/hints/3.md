# Hint 3

If the villager crawls, or its speed changes with the frame rate, the walking velocity is being multiplied by `delta`, or the code runs in `_process()`. `move_and_slide()` already moves the body by `velocity` over one physics step, so set it in meters per second and call it from `_physics_process()`.

If it walks but floats, or falls but never walks, the code overwrites the part of `velocity` the other needs. Set only `x` and `z` from `heading() * speed`, and add `get_gravity() * delta` to the whole of it: gravity is an acceleration, so that part does take `delta`.

If it falls through the floor or climbs the stone slope, something other than `move_and_slide()` is moving it: setting `position` skips collisions. The ramp counts as floor and the slope as wall because of `floor_max_angle`, 45 degrees by default.
