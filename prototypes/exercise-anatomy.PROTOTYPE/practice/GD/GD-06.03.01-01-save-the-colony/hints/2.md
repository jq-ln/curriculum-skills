# Hint 2

- Put villagers and fields in a group, such as `"Persist"`, and give each a `save()` that returns a Dictionary including `"filename": get_scene_file_path()` and `"parent": get_parent().get_path()`.
- JSON has no Vector3, so store the position as three numbers.
- To save, open the file for writing and store `JSON.stringify(node.save())` as one line for each member of the group.
- To load, first `queue_free()` every member of the group. Then, for each line, load the scene file, instantiate it, add it under `get_node(parent)` and put its values back.
