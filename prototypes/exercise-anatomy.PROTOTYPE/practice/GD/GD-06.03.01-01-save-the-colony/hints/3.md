# Hint 3

If everything passes except the whole-number check: JSON brings every number back as a float. A property declared as an `int` converts the float as it's set, but the numbers inside the `inventory` Dictionary stay floats. Convert them back with `int()` as you restore the inventory.

If loading twice doubles the colony, or the first load leaves the scrambled villagers in place, the loader isn't freeing the group's members before it rebuilds. Read the file with `while file.get_position() < file.get_length():` and skip any line `JSON.parse()` rejects.
