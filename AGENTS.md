# Agent instructions

## Session start

At the start of every session, before any other work, read `docs/workflow/branches.md#pruning` and run `prune` as it says.

## Branches and worktrees

When creating, resuming or checking out a branch or a worktree, read `docs/workflow/branches.md`.

## Writing style

When writing any text (commits, issues, PRs, review comments, replies, code comments, docs), read `docs/style.md`.

## Issues

When filing, triaging or claiming issues, read `docs/workflow/issues.md`.

## Commits and PRs

When writing a PR title or body, read `docs/workflow/commits.md`.

## Review

When reviewing a PR, or responding to review comments on your PR, read `docs/workflow/review.md`.

## Releases

When touching releases (the Release PR, `CHANGELOG.md`, `version.txt`, or the release-please config or manifest), read `docs/workflow/releases.md`.

## CI

When a check fails on a PR, or before you edit a workflow, read `docs/workflow/ci.md`.

## Domain references

When adding or changing a Domain reference under `skills/build-exercises/references/domains/`, read `docs/domain-reference.md`.

## Glossary and ADRs

When naming a domain concept in an issue, PR, test or code, editing `GLOSSARY.md` or `docs/adr/`, or changing code or docs in an area an ADR in `docs/adr/` covers, read `docs/workflow/domain.md`.
